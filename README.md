# Repository Overview

**Author:** Christian Bjerregaard

**Email:** s224389@dtu.dk

**Affiliation:** [QIM](https://qim.dk), in collaboration with DTU Construct

This repository presents a showcase of tracking particles and voids through 3D X-ray CT scans of a beam at successive deformation steps. The workflow identifies these features, follows their movement between scans, and exports measurements for further analysis.

For the non-technical report with illustrations, see [report.md](report.md). The images used in the report are in [assets/](assets/).

## Project Code

The tracking implementation, notebooks and running instructions are available in [consult-particle-tracking](https://github.com/qim-center/consult-particle-tracking).
